Element Atlas.

The periodic table, made approachable. A small interactive learning tool for exploring the elements one by one.

Follow developmentAll products
The problem

Too much to memorize. Not enough to explore.

A periodic table can feel like a wall of symbols. Our goal is to make each element a discoverable story: name, symbol, atomic number and context, presented in a calm interface.

Design direction

Learn by exploring

  • Browse the periodic table interactively.
  • Open clear, approachable element information.
  • Make discovery easy for curious beginners.

These are product intentions, not a promise that every feature is shipped.

Availability

Not released yet.

A prototype exists. Element Atlas is pre-release, with no public purchase or download available.
